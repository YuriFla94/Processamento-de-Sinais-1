# Processamento de Sinais I

Repositório contendo os códigos e arquivos utilizados nas aulas práticas da disciplina de Processamento de Sinais I.

## Conteúdo

* **Aula 01:** Amostragem, resposta ao impulso e convolução
* **Aula 02:** Análise espectral e reamostragem
* **Aula 03:** Filtros, polos/zeros e recuperação de sinal
* **Aula 04:** DTFT/DFT e compressão de áudio

## Requisitos

Para executar os códigos, são necessários:
* Python 3.x
* NumPy
* SciPy
* Matplotlib
* Jupyter Notebook

## Instalação

Clone o repositório:
```bash
git clone https://github.com/YuriFla94/Processamento-de-Sinais-1.git
```

Entre na pasta:
```bash
cd Processamento-de-Sinais-1
```

Instale as dependências:
```bash
pip install -r requirements.txt
```

## Como utilizar

Cada aula possui uma pasta própria. Por exemplo:
```bash
cd aula-01
```

Os códigos podem ser executados utilizando:
```bash
python codigo/experimento.py
```
ou, caso seja utilizado Jupyter Notebook:
```bash
jupyter notebook
```

## Organização das pastas

* `aula-01/`
  * `codigo/` -> códigos da atividade
  * `dados/` -> arquivos de entrada
  * `resultados/` -> resultados gerados

## Resultados

Os resultados apresentados no relatório podem ser reproduzidos executando os códigos disponíveis no repositório.
